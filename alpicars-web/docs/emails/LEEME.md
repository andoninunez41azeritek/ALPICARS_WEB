# Emails de Supabase en español

Supabase → Authentication → Emails → Templates. En cada plantilla, pega el HTML del archivo correspondiente y cambia el asunto:

| Plantilla de Supabase | Archivo | Asunto |
|---|---|---|
| Confirm signup | confirmar-registro.html | Confirma tu cuenta de AlpiCars |
| Reset password | recuperar-contrasena.html | Crea tu nueva contraseña de AlpiCars |
| Magic link | enlace-de-acceso.html | Tu enlace para entrar en AlpiCars |
| Change email address | cambio-de-email.html | Confirma tu nuevo email en AlpiCars |
